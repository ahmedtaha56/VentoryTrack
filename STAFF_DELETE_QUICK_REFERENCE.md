# Staff Delete Feature - Quick Reference\n\n## What's New? 🎉\n\nStaff members can now be **DELETED** with real-time updates to the entire team!\n\n## Who Can Delete? 👥\n\n✅ **Admin** - Can delete any staff member\n✅ **Manager** - Can delete staff members (NEW FEATURE)\n❌ **Staff** - Cannot delete\n❌ **Viewer** - Cannot delete\n\n## How to Delete a Staff Member? 🗑️\n\n1. Go to **Staff Management** screen\n2. Find the staff member you want to delete\n3. Click the red **Delete** button\n4. Confirm the deletion in the popup\n5. Staff member is deleted immediately\n6. **All team members see the update in real-time!**\n\n## What Happens When You Delete? 📊\n\n✓ Staff member is removed from the system\n✓ User account is deleted from Supabase Auth\n✓ User profile is removed from database\n✓ Staff permissions are cleaned up\n✓ **Notification sent to all other team members**\n✓ **All screens update automatically (real-time)**\n\n## Files That Changed 📝\n\n1. **config/roles.js**\n   - Added delete permission for Manager role\n\n2. **lib/database.js**\n   - Added `deleteStaffUser()` function\n   - Added `subscribeToStaffChanges()` function\n\n3. **screens/staff/Staffmanagementscreen.js**\n   - Added delete button to UI\n   - Added delete handler function\n   - Added real-time subscription setup\n   - Updated state management\n   - Added styling for delete button\n\n## Key Features 🌟\n\n### 1. Permission-Based\n- Only authorized users can see the delete button\n- Admin always has access\n- Manager now has access (new)\n- Others cannot delete\n\n### 2. Confirmation Required\n- Cannot accidentally delete\n- Must confirm in dialog\n- Shows staff member name\n- Clear warning message\n\n### 3. Real-Time Sync\n- All users see deleted staff removed instantly\n- No need to refresh manually\n- Automatic notification to team\n- Works across all devices/screens\n\n### 4. Proper Cleanup\n- Deletes permissions first\n- Removes from auth system\n- Removes user profile\n- Creates audit notification\n\n## Code Examples 💻\n\n### Check Delete Permission\n```javascript\nconst { canDelete } = getFeaturePermissions('users');\n\nif (canDelete) {\n  // Show delete button\n}\n```\n\n### Delete a Staff Member\n```javascript\nconst result = await deleteStaffUser(\n  supabase,\n  staffId,\n  staffName,\n  actorName\n);\n\nif (result.success) {\n  console.log('Staff deleted successfully');\n} else {\n  console.error('Failed to delete:', result.error);\n}\n```\n\n### Subscribe to Staff Changes\n```javascript\nconst unsubscribe = subscribeToStaffChanges(\n  supabase,\n  (changeType) => {\n    console.log('Staff changed:', changeType);\n    loadStaff(); // Refresh the list\n  }\n);\n\n// Clean up when done\nunsubscribe();\n```\n\n## UI Elements 🎨\n\n### Delete Button\n- **Color:** Red (#ff3333)\n- **Background:** Light Red (#ffebee)\n- **Icon:** Trash icon 🗑️\n- **Position:** Right side of staff card\n- **Label:** \"Delete\" or \"Deleting...\"\n\n### Confirmation Dialog\n- **Title:** \"Delete Staff Member\"\n- **Message:** Shows staff name and warning\n- **Buttons:** Cancel and Delete (destructive)\n\n### Success Message\n- **Type:** Alert\n- **Message:** \"[Name] has been deleted.\"\n\n## Real-Time Updates Flow 🔄\n\n```\nDelete Action\n    ↓\nDatabase Updated\n    ↓\nSupabase Detects Change\n    ↓\nPush Notification to All Clients\n    ↓\nSubscription Callback Triggered\n    ↓\nStaff List Reloaded\n    ↓\nUI Updated for All Users\n```\n\n## Notification Sent 📢\n\n- **Type:** `staff_delete`\n- **Message:** \"[Actor Name] deleted staff member: [Staff Name].\"\n- **Sent To:** All other team members (not the deleter)\n- **View:** Notifications screen\n\n## Testing Guide 🧪\n\n### Test as Admin\n1.
